루디아푸드 생산관리 개인정보처리방침

루디아푸드 생산관리(이하 "앱")는 직원의 생산관리 업무를 지원하기 위해 제공됩니다.

시행일: 2026년 7월 30일

1. 개인정보 수집 및 공유

개발자는 개인정보를 수집하거나 제3자와 공유하지 않습니다. 앱은 광고, 분석 도구, 인터넷 서버 또는 외부 동기화 기능을 사용하지 않습니다.

2. 기기 내부 저장

재고실사, 로스율 기록 등 앱에서 작성한 업무 데이터는 사용자의 기기 내부에 저장됩니다. 이 데이터는 앱 개발자에게 자동으로 전송되지 않습니다.

3. 사용자가 지시한 파일 내보내기

사용자가 직접 내보내기를 실행한 경우에만 CSV와 백업 파일을 생성하여 사용자가 선택한 위치 또는 공유 대상으로 내보냅니다. 내보낸 파일의 보관과 전달은 사용자가 선택하고 관리합니다.

4. Android 자동 백업

앱은 Android 자동 백업을 사용하지 않습니다. 따라서 앱의 내부 업무 데이터가 Android 자동 백업을 통해 클라우드에 저장되지 않습니다.

5. 데이터 삭제

앱에 저장된 업무 데이터는 Android 설정에서 앱의 저장공간을 삭제하거나 앱을 제거하면 삭제할 수 있습니다. 사용자가 내보낸 CSV와 백업 파일은 저장하거나 공유한 위치에서 직접 삭제해야 합니다.
