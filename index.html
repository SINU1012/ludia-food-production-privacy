루디아푸드 생산관리 개인정보처리방침

루디아푸드 생산관리(이하 "앱")는 허용된 직원의 생산관리 업무를 지원하기 위해 제공됩니다.

시행일: 2026년 7월 31일

1. 처리하는 정보

앱은 Google 로그인 과정에서 Google 계정 이메일 주소와 Firebase 사용자 식별자를 처리합니다. Firebase Authentication은 로그인 보안과 서비스 제공을 위해 IP 주소와 사용자 에이전트 문자열, Firebase Android App ID를 자동 처리합니다. Firebase App Check와 Google Play Integrity는 앱·기기 무결성 정보를 확인하기 위해 무결성 증명 자료, Play Integrity 무결성 토큰과 App Check 토큰을 처리합니다. 또한 앱은 허용 계정 여부와 역할, 재고실사·로스율 기록, 사용자가 입력한 작업자명, 입력·수정 시각, 동시 입력과 재시도에 필요한 무작위 기기 설치 식별자·작업 식별자·동기화 상태를 처리합니다.

2. 이용 목적

위 정보는 허용된 직원 확인, 여러 사용자와 여러 휴대폰 사이의 공동 업무 기록 동기화, 동시 입력 보존, 오프라인 캐시와 재시도, 인증 보안과 부정 사용 방지, 계정 삭제 요청 처리에만 사용합니다. 앱은 광고 또는 사용자 행동 분석 기능을 사용하지 않습니다.

3. 클라우드 저장 및 공동 이용

앱은 Google Firebase Authentication과 Cloud Firestore를 사용합니다. 업무 기록은 Firebase 클라우드에 저장되며 허용된 루디아푸드 직원이 동일한 재고실사·로스율 데이터를 공동으로 조회하고 수정할 수 있습니다. Google Firebase 서비스와 주고받는 데이터는 HTTPS(TLS)로 전송 중 암호화됩니다. Google은 Firebase 서비스 제공자로서 인증 정보, 클라우드 데이터, 보안 확인 자료를 처리합니다. 개발자는 업무 기록을 판매하거나 광고 목적으로 이용하지 않습니다.

4. v3 기존 기록의 최초 등록

지정된 기존 기기에 보존된 v3 재고실사·로스율 기록은 최초 연결 시 한 번 구조화된 업무 기록으로 Firebase에 등록될 수 있습니다. 기존 기기의 로컬 원본은 이 등록 과정에서 자동 삭제하지 않습니다.

5. 기기 내부 저장과 오프라인 처리

앱은 빠른 표시와 오프라인 사용을 위해 Firebase 캐시, 계정별 업무 상태, 재전송을 위한 미처리 변경 기록을 기기에 저장할 수 있습니다. 로그아웃하면 이전 계정의 업무 데이터는 앱 화면에 표시되지 않습니다. Android 자동 백업을 사용하지 않습니다. 앱 저장공간 삭제 또는 앱 제거는 기기 내부 자료만 삭제하며, 앱 제거만으로 서버의 공동 업무 기록은 삭제되지 않습니다.

6. 사용자가 지시한 CSV 공유

재고실사 CSV 공유를 직접 실행한 경우에만 임시 CSV 파일을 만들고 사용자가 선택한 앱 또는 대상으로 전달합니다. 공유된 파일의 보관과 전달은 사용자가 선택하고 관리합니다.

7. 계정 및 데이터 삭제 요청

앱 첫 화면의 “계정 삭제 요청”을 이용하면 해당 계정의 허용 상태를 비활성화하고 삭제 요청을 등록한 뒤 로그아웃합니다. 이 기능은 삭제 완료가 아니라 처리 대기 요청을 등록합니다. 요청 즉시 Firebase Authentication 계정이나 서버 자료가 자동 삭제되는 것은 아니며, 관리자가 요청을 확인한 뒤 수동으로 처리합니다. 처리 대상에는 Firebase Authentication 사용자 계정과 인증 식별자(UID) 등 해당 계정에 연결된 개인 식별 정보가 포함됩니다. 현재 소유자 계정은 요청 전에 관리자 변경이 필요하며 앱에서 이를 안내합니다. 회사의 공동 업무 기록은 다른 직원의 업무 연속성을 위해 계정 요청과 별도로 유지될 수 있습니다. 현재 앱은 자동 보존기간 삭제 기능은 사용하지 않습니다. 계정 삭제 요청 안내에서 앱에 로그인할 수 없는 경우의 요청 방법과 처리 범위를 확인할 수 있습니다.
